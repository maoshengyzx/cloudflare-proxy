快速上手

两种使用方式，选择最适合你的

将 github.com 替换为你的代理域名即可：

# Clone 仓库 git clone https://your-domain.com/https://github.com/user/repo.git # 下载 Release wget https://your-domain.com/https://github.com/user/repo/releases/download/v1.0/file.tar.gz

修改 Docker daemon 配置，添加 registry mirror：

// /etc/docker/daemon.json { "registry-mirrors": [ "https://your-domain.com" ] }

然后执行 systemctl restart docker 生效。

常见问题

关于 Cloudflare Proxy 的一切

如何部署到自己的 Cloudflare Pages？
Fork 本项目仓库，在 Cloudflare Pages Dashboard 中连接 GitHub 仓库，设置构建命令为空（纯静态），部署目录为 /，_worker.js 会自动被 Pages 识别。
是否需要 Cloudflare Workers 付费？
完全不需要。Cloudflare Workers 免费计划提供每日 10 万次请求额度，个人使用绰绰有余。Pages 静态托管也完全免费。
代理速度有多快？
Cloudflare 全球 CDN 节点，延迟通常在 50-200ms。连接到 GitHub 源站速度极快，实际下载速度取决于你的本地带宽和 Cloudflare 节点质量。
支持哪些平台的加速？
GitHub (Release, Clone, Raw, Archive)、Docker Hub、GHCR、Quay.io、NPM Registry、PyPI、Crates.io。通过 Worker 配置可扩展支持更多上游。
