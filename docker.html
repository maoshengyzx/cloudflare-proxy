Docker Registry Mirror

Docker 镜像 加速代理

配置一次，永久加速。支持 Docker Hub、GHCR、Quay.io 等主流 Registry。

一键配置镜像加速

根据你的系统选择对应的配置方式

# 编辑 daemon.json sudo tee /etc/docker/daemon.json <<-EOF { "registry-mirrors": [ "https://your-domain.com" ] } EOF # 重启 Docker sudo systemctl daemon-reload sudo systemctl restart docker # 验证 docker info | grep "Registry Mirrors"
# Docker Desktop → Settings → Docker Engine # 添加以下内容到配置中: { "registry-mirrors": [ "https://your-domain.com" ] } # 点击 "Apply & Restart" 生效
# Docker Desktop → Settings → Docker Engine # 编辑配置 JSON，添加 registry-mirrors: { "registry-mirrors": [ "https://your-domain.com" ] } # 点击 "Apply & Restart" 生效
# 单次使用代理拉取 (不改配置) docker pull your-domain.com/library/nginx:latest # 其他 Registry 也适用 docker pull your-domain.com/ghcr.io/owner/image:tag

验证加速效果

配置完成后，用以下命令确认加速已生效

查看生效的 Mirror

docker info

输出中应包含 Registry Mirrors 字段，值为你的代理地址。

测试拉取速度

time docker pull nginx:alpine

第一次拉取会在 CDN 回源，后续请求命中 Cache 后速度更快。
