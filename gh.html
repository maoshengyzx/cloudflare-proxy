GitHub 加速代理

使用方式

将原始地址附加到代理域名后面即可，支持以下场景

Git Clone 加速

克隆仓库时自动通过代理加速

# 通过代理克隆仓库 git clone https://your-domain.com/https://github.com/user/repo.git # 设置全局代理（一劳永逸） git config --global url."https://your-domain.com/https://github.com/".insteadOf "https://github.com/"

Release 下载加速

加速下载 GitHub Release 附件

# wget 下载 wget https://your-domain.com/https://github.com/user/repo/releases/download/v1.0/binary.tar.gz # curl 下载 curl -LO https://your-domain.com/https://github.com/user/repo/releases/download/v1.0/binary.tar.gz

Raw 文件 & Archive 加速

直链 Raw 内容和源码压缩包

# Raw 文件 原始: https://raw.githubusercontent.com/user/repo/main/script.sh 代理: https://your-domain.com/https://raw.githubusercontent.com/user/repo/main/script.sh # 源码 Archive 原始: https://github.com/user/repo/archive/main.zip 代理: https://your-domain.com/https://github.com/user/repo/archive/main.zip

加速原理

Cloudflare Worker 在全球边缘节点帮你转发请求

你的终端 git clone / wget
Cloudflare CDN 边缘节点转发
GitHub 源站 全球高带宽

请求经过 Cloudflare 全球节点时路由到最近的数据中心，
由其与 GitHub 源站建立高速连接回传数据，有效绕过网络限制。
